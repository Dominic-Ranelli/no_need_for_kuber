Something interesting I learned in general upkeep, when making changes to code, I should run:
For tests:
PYTHONPATH=. uv run pytest --cov=app --cov-report=term-missing

For testing latency:
PYTHONPATH=. uv run python tests/test_latency.py

To catch mismatches:
mypy app/main.py

To update uv:
uv self update

For uv:
uv sync

For code quality:
uv run ruff format
