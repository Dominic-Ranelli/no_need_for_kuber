Something interesting I learned in general upkeep, when making changes to code, I should run:
Running on docker:
docker build --pull --no-cache -t myimage -f docker/Dockerfile .
docker run -p 8080:80 myimage


Update requirements:
uv pip compile pyproject.toml -o requirements.txt --generate-hashes

View build steps:
docker build --progress=plain -f docker/Dockerfile .

For tests:
PYTHONPATH=. uv run pytest --cov=app --cov-report=term-missing

For testing latency:
PYTHONPATH=. uv run python tests/test_latency.py

To catch mismatches:
mypy app/main.py

To update uv:
uv self update

For uv:
uv sync

For code quality:
uv run ruff format
